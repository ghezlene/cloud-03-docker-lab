> Package applications and their dependencies into reproducible, portable containers.

## Overview

Containers provide a consistent environment for running applications across development, testing, and production.

This project explores Docker from its fundamental concepts to multi-container application deployment.

The goal is to understand not only how to run containers, but also how they are built, connected, configured, and maintained.

## Learning Objectives

- Understand containerization and virtualization.
- Explore Docker architecture.
- Understand images and containers.
- Create Dockerfiles.
- Build and tag custom images.
- Manage container lifecycle.
- Understand Docker networking.
- Persist data using volumes and bind mounts.
- Deploy multi-container applications using Docker Compose.
- Configure environment variables.
- Inspect logs and troubleshoot containers.
- Improve image size and security.

## Practical Projects

### 1. Container Fundamentals

- Run existing images.
- Create and inspect containers.
- Explore container lifecycle commands.
- Understand image layers.

### 2. Custom Application Image

- Create a Dockerfile.
- Build an application image.
- Configure exposed ports.
- Use environment variables.
- Improve image construction.

### 3. Multi-Container Application

Deploy a sample application composed of:

- Frontend.
- Backend API.
- Database.

Use Docker Compose to manage the complete environment.

### 4. Container Operations

- Configure persistent volumes.
- Connect containers through networks.
- Inspect logs and resource usage.
- Configure health checks.
- Troubleshoot failed containers.
